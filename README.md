# Enactus IUCA — адаптивный шаблон сайта

## Быстрый запуск
Откройте `index.html` в браузере. Для локального сервера из папки проекта: `python3 -m http.server 8000`, затем откройте `http://localhost:8000`.

## Стек
Чистый HTML/CSS/JavaScript, без npm, фреймворков и сборки. Работает на телефонах и компьютерах. Навигация через URL-хеши (`#projects`, `#team`, `#project/kuyruq`).

## Файлы
- `index.html` — каркас сайта, меню и подвал.
- `styles.css` — стили, цветовые токены, адаптивность.
- `site-data.js` — проекты, карточки команды, события и партнёры.
- `app.js` — рендеринг страниц и интерактивность.
- `assets/brand-dark.png`, `assets/brand-light.png` — предоставленные варианты логотипа.
- `assets/frog-original.png` — фрагмент оригинальной графики из предоставленного логотипа (не перерисован).

## Страницы
Главная, О нас, Проекты, детальная страница проекта, Команда, События, Партнёры, Присоединиться.

## ВАЖНО: что ещё сделать до публикации
1. Подтвердить официальные логотипы, разрешение на использование бренда и финальные бренд-материалы. Проверить прозрачность PNG на разных фонах.
2. Заполнить `site-data.js` настоящими ФИО, фотографиями, событиями, статусами проектов и подтверждёнными партнёрами. Все численные KPI пока сознательно исключены, чтобы не публиковать выдуманные результаты.

5. Для SEO и прямых URL желательно перейти с hash-навигации на роутинг с серверным рендерингом или статической генерацией.
6. Добавить CMS/админку, если команда планирует регулярно публиковать новости и события.
7. Проверить доступность, производительность и изображения; заменить emoji-обложки проектов на реальные согласованные изображения.

## Дальнейшее развитие
Вариант 1: оставить статическим сайтом и развернуть на GitHub Pages / Netlify / Vercel.
Вариант 2: перенести компоненты на React/Next.js, добавить API, БД и админку.

Демонстрационная форма ничего не отправляет. Это сознательное ограничение, а не ошибка.
